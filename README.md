Seja bem-vindo ao SAMMIBB! O Sistena de Análise e Monitoramento de Membros da Igreja Batista Betel. 
Se você deseja implementar esse programa para a sua igreja, o projeto é Open Source.
Para rodar o projeto no seu computador, siga os seguintes passos:
1. Tenha o VS CODE instalado;
2. Entre no VS CODE e abra a pasta que você irá utilizar para clonar o projeto;
3. Abra o terminal do VS CODE e digite o comando "git clone https://github.com/pedroarthurgt/Projeto-de-PDS";
5. Depois de verificar que os arquivos estão corretos, continue no terminal;
6. Escreva o comando "python -m venv ./venv" para criar o seu ambiente virtual;
7. Depois de criar o ambiente virtual, é necessário ativá-lo usando o comando ".\venv\Scripts\activate";
8. Por fim, digite o comando "python manage.py runserver" para rodar o SAMMIBB.
   
Pronto! Você está rodando nosso projeto.
