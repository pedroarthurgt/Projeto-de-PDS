Seja bem-vindo ao SAMMIBB! O Sistena de Análise e Monitoramento de Membros da Igreja Batista Betel. 
Se você deseja implementar esse programa para a sua igreja, o projeto é Open Source.
Para rodar o projeto no seu computador, siga os seguintes passos:
1. Tenha o VS CODE instalado;
2. Abra o terminal e digite o comando "git clone https://github.com/Everton4814/Samibb";
3. Depois de verificar que os arquivos estão corretos, continue no terminal;
4. Escreva o comando "python -m venv ./venv" para criar o seu ambiente virtual;
5. Depois de criar o ambiente virtual, é necessário ativá-lo usando o comando ".\venv\Scripts\activate";
6. Por fim, digite o comando "python manage.py runserver" para rodar o SAMMIBB.
   
Pronto! Você está rodando nosso projeto.
